## auto mode について（要点）

- LiteLLM 経由でも `permissionMode: 'auto'` は動く。ただし分類器は同じ gateway に Claude Sonnet 4.6 以上を求める（`settings.autoMode.classifierModel`）。Claude 以外のモデルだけの構成では使えず、規則表に落ちる。
- 分類器の費用は SDK の使用量に入らない（Budget は少なく数える。未対応）。

## 残っているリスクと課題

1. **字面判定の限界**：`pnpm test` などが実行するスクリプトの中身は見えない。本当の境界は OS レベルの隔離（別ユーザー・コンテナ・egress プロキシ）。
2. **同一ユーザーのトークン**：エージェントのコードは理屈の上では `daemon.json` を読めてしまう（security-3）。
3. **実機未確認**：本物の LiteLLM と本物の分類器での誤検知・見逃しの頻度。
4. Orchestrator の模擬モデルが「統合候補を人間のレビューに回す」を 3 回くり返す（デモの Timeline が少しうるさい）。
