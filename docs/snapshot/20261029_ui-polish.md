# 2026-10-29 UI の手触り（track/ui-polish）

日常使いの手触りを詰めた記録。仕様は `docs/persistent/ui-design.md`（同じブランチで更新済み）。

## 入ったもの

- **Task ボード**：司令室の `[エージェント | Task]`（`T`）。Worker 未起動の Task も状態ごとに並び、`R` 実行 / `F` 差し戻し / `Ctrl+Shift+Backspace` 中止。差し戻しは `task.retry` があれば使い、なければ `task.update(ready)` → `task.spawnWorker({ instructions })` で同じことをする。
- **プロジェクト追加の事前確認**：`project.inspectRepo` があれば入力中に確認（リポジトリでなければ作成不可、ルート・ブランチ・テストコマンドを反映、未コミットの変更を警告）。結果の形は `model/repo.ts` で寛容に読む。
- **通知**：`app/attention.ts`（承認待ち・失敗・統合の反映待ち・Orchestrator の報告）と `lib/notify.ts`（Tauri の `window.__TAURI__.notification`、なければ Web Notification）。設定にトグル。10 秒に 1 回 + 要約。
- **チャット**：メッセージの浮動ツールバー（コピー / 編集して送り直す / 再試行）、`↑` で未応答の最後のメッセージを編集、reasoning を畳む、キャレットは末尾（コード内も）で流れている間は点灯、長い自分のメッセージを畳む、Control API の呼び出しを「Task を作成: 「…」」のように表示。ブロックの同一性を保ち markdown を差分で字句解析（長い会話でフレームごとに全文を再解析しない）。
- **パレット**：メッセージ検索（`session.search`、語を強調、該当メッセージへ移動）、一致なしの文言、次の承認・承認、統合のレビュー、Task ボード、Task の実行・中止、権限の付与・取り消し、テーマの直接切替、プロジェクト名での切替、ピン留め・アーカイブ、通知・タイムライン詳細の切替。
- **タイムライン**：配管イベントを既定で隠す（`詳細なイベントも表示`）、主体バッジ、直前からの間隔、出来事の場所へ移動、フィルタの保存。
- **e2e**：`e2e:board`（Task ボード + パレット検索、本物のデーモン）。`screenshots.js` に `--theme` / `--size`。

## スクリーンショット

`node e2e/screenshots.js --theme dark|light --size 1440x900|1100x720` を scene（本物のデーモン）に対して撮影。主要 15 画面 × 2 テーマ × 2 幅。出力は OS の一時ディレクトリ（リポジトリには置かない）。

## 残り

- `A`（このRunでは今後も許可）は契約待ち。`x` の複数選択と一括操作は未着手。
- OS 通知のクリックで該当場所を開くのはブラウザのみ（Tauri のプラグインはクリックを返さない）。Tauri 側のプラグイン登録・権限は shell / packaging の担当。
- `project.inspectRepo` / `task.retry` / `system.shutdown` は結果の形を推測して寛容に読んでいる。デーモン側で形が決まったら `model/repo.ts`・`reworkTask` を合わせる。
- 差し戻しのフォールバック（review → ready → spawnWorker）は 2 回の呼び出しで、途中で失敗すると review に戻すだけ（原子的ではない）。
