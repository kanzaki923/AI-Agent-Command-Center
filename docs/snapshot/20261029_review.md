# 2026-10-29 レビュー指摘の修正

`track/align` を `vertical-slice` にマージ（コンフリクトなし）してから、独立に検証済みのレビュー指摘 33 件を直した。偽陽性と判断したものはない。

## 判断したこと

- **統合テストの承認**：concept §6.1 は「テスト → 人間にレビュー対象を提示」の順なので、テストは承認の前に走る。ただしエージェントの書いたコードをユーザー権限で動かすことは Bash と同じ重さなので、人間が始めた試行（その人の判断）以外は 1 回の承認を挟んだ。UI は統合のカードで「統合後のテストを実行しますか？」と尋ねる。Orchestrator の流れは承認が 1 回増える。
- **トークン**：同じユーザーのプロセスを区別する手段がないため、「human 専用」の保証は「エージェントのコードは人間の判断なしに動かない」ことに依存する、と architecture §2.1 に明記した。
