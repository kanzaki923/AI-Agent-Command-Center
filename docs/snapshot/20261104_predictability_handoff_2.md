## 残っていること

1. **作業場所の切り替えをデーモンに強制させる**。方針は決めてある：ホームの切り替えのいちばん左を `自動`（右腕が決める）にし、フォルダ・コードを選んだら `session.send` の `workPlace { kind, projectId }`（hint の meta に `place`）で渡して、`assistant.startWork` が右腕の指定より優先する（モデルの `workModel` と同じやり方）。`session.send`・`api.ts`・`domain.ts` を別の作業（worktree `ai-conversations`、forward / 会話システム）が触っているので、それがマージされてから。
2. **OS の通知を押しても会話が開かない**（Tauri）。`tauri-plugin-notification` はデスクトップでクリックを返さない。Rust 側で `tauri-winrt-notification` の `on_activated` を使い、ウィンドウを出してイベントで会話を開く形になる。実機で確かめる必要がある。
3. 細かいもの：レーンの `+N` は根の会話を開く（隠れた子はデーモンが切っているので、その場では広げられない）、`Ctrl+F` は画面で意味が変わる。
