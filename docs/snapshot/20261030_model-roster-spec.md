# 2026-10-30 仕様：使うモデルの名簿（上から順に当てはめる）

「既定のモデル」を意識させない、でも勝手に変えない、そして会社のガイドライン（「Luna を基本、画面設計は Sonnet、文章は Gemini…」）をそのまま持てるようにする。

## 経緯

1. 右腕に送ると「モデルが設定されていません」で失敗した（ChatGPT でサインインしただけで既定のモデルが空）。
2. まず「おまかせ」（`llm/autoModel.ts`）：指定がなければ実行のたびに接続先の一覧から役割と予算で選ぶ。エラーは消えたが、モデルは頻繁に変わり、費用も大きく違うので、毎回の完全自動は不安。
3. 軽い / 標準 / 強いの 3 段を検討 → 3 つしか選べず、複数プロバイダの旨味が減る。
4. **名簿**に決めた：いつでも使えるモデルを並べ、各行に「こういうとき」。上から順に見て最初に当てはまったものを使う。最下段は固定の「それ以外」。

## 形

- **名簿**（`settings.modelRules`）：`{ model, when }` の配列。順番が優先度（上から順に評価、最初に当てはまったもの）。最大 20 行、`when` は 200 字まで。
- **それ以外**（`settings.defaultModel`、名簿の最下段に固定）：どの行にも当てはまらないとき。**人が自分で始めた会話もこれで始まる**（ピッカーで変えられる）。右腕と監督役自身もこれで動く（`settings.assistant.model` があれば右腕はそちら）。
- **選ぶのは割り振る側**：右腕（`assistant.startWork`）と監督役（`session.spawn`）が、作業の内容と名簿を照らして `model` を渡す。判断のための追加のモデル呼び出しはしない。迷ったら渡さない（＝それ以外）。
- **名簿の外は使わせない**（Core Daemon が強制）：エージェント（`actor.kind === 'agent'`）がセッションに名前つきのモデルを付けるとき（`session.create` / `session.spawn` / `assistant.startWork` / `session.update` / `session.send` の `model`）、名簿の行・それ以外・`mock/*` のどれかでなければ `invalid_params`。人は自由。
- **エージェント（Claude Code）に使えるモデル**：LiteLLM があれば接頭辞なしの名前、なければ Claude のモデルだけ。子を `mode: agent` で作るときに使えない名簿の行を指定したら、理由つきで拒否（「エージェントには Claude のモデルか LiteLLM のモデルを」）。プロンプトでも行ごとに `agent: yes/no` を示す。

## 初めのとき

- それ以外が空で接続先があるとき、最初の実行で `autoModel` が選び、**`defaultModel` に保存する**（以後は固定。勝手に変えない）。名簿も空なら、速いモデルが別にあれば 1 行足す（`調べもの・要約・定型の作業`）。どちらも設定で見えて、変えられる。
- 実行時の毎回の自動選択はやめる（保存した 1 回だけ）。

## 費用を意識できるように（concept §5.2）

- **名簿の各行**に、そのモデルでの典型的な 1 回（20 呼び出し × 入力 8k・出力 800）の目安 `約 $0.48/回` と、ここ 30 日の実際の費用 `30 日 $3.20` を出す。契約枠（ChatGPT）は `契約枠`。目安は `models.list` の `ModelInfo.runUsd`（デーモンが単価表から出す。契約枠は 0、不明は null）。実費は `cost.summary`（`groupBy: model`, `30d`）。
- **プロンプト**：右腕と監督役に名簿を番号つきで渡し、各行に目安の費用を添える。「子の予算に収まらない行は飛ばして下へ」。予算そのものの強制はこれまでどおり Core Daemon。
- 行ごとの金額の上限・「使う前に聞く」は入れない（木ごとの予算で上限は守れている。要望が出てから）。

## 画面

- 設定の主欄に `モデル` の行：要約（`gpt-6.1-sol ほか 2`）と `変更`。押すとその場に名簿（接続の `変更` と同じ開き方）。
- 名簿：行ごとに つまみ（ドラッグで並び替え。キーボードは Alt+↑↓）・番号・モデル（ピッカー）・こういうとき（入力欄、離れたら保存）・費用（目安と 30 日）・削除。下に `モデルを足す`。罫線で区切って最下段に `それ以外`（つまみの代わりに錠、モデルだけ変えられる、説明は「あなたの会話もこれで始まる」）。
- 会話のピッカー：「おまかせ」はやめ、未設定なら「それ以外」のモデル名を出す。名簿のモデルを上に。

## あとで

- 「ガイドラインを貼って作る」：社内文書から右腕が名簿の案を作り、人が確かめて保存。
- 新しいモデルが出たら「名簿に足しますか」の提案。名簿のモデルが一覧から消えたら知らせる。
- 子のチップにモデル名と、当てはまった行（ホバー）。
