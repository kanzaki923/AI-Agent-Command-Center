# 2026-11-06 引き継ぎ：v0.1.3 答えたモデルを正しく出す

v0.1.2 で、エージェントの会話が Claude Code で動くようになった。ところが画面にも記録にも GPT のモデル名が出ていた。

- 会話を作るときに、設定の既定のモデル（`openai/gpt-6.1-sol`）が付いた。
- Claude Code は GPT を動かせないので、自分の既定のモデル（実際は `claude-opus-5-5`）で答えていた。
- 発言・Run・費用の台帳は、会話のモデルをそのまま書いていた。

Claude のつもりで GPT と読める表示は論外なので、答えたモデルを正しく出すように直した。

## 直したもの

- **答えたモデルを記録する**：`AgentEvent` に `model` を足した。Claude Code は `system/init` と本体の API メッセージの `message.model` から知らせる（サブエージェントと `<synthetic>` は数えない）。実行器はそれを発言の `model` にして、`ctl.setModel` で Run の `model` を替える。台帳は Run の `model` で記帳するので、費用も答えたモデルの名前になる。
- **モックはモックと言う**：会話のモデルが何でも、`mock/mock-agent`（モックのモデルならそのモデル）を名乗る。
- **動かせないモデルを付けない**：エージェントの会話は、既定のモデル（メンバー・プロジェクト・設定）をランタイムが動かせるときだけ受け継ぎ、そうでなければ `model: null`（Claude Code の既定）。動かせないモデルを名指しすると、人でも `session.create` / `update` / `send` が理由つきで断る。
- **画面**：エージェントの会話の見出しのチップは、会話のモデル（動かせるとき）、なければ最後に答えたモデル、まだ答えていなければ `Claude Code の既定`。一覧は Claude Code が動かせるモデルだけ。新しい会話とホームの欄も、作業場所がフォルダかコードなら同じ。チップにカーソルを合わせると正式名（`claude-opus-5-5`）が出る。

## 確かめたこと

- lint・型チェック・テスト（全体の並列実行で、本物の CLI を起動する `sdk-contract.test.ts` の 1 件だけが時間切れになった。単体では 26 件とも通る）。
- 本物の Claude Code（別の `ACC_HOME`、既定のモデルを GPT にした状態）で README について聞いた：
  - 会話のモデルは null。
  - Run・発言・台帳はどれも `claude-opus-5-5`。
  - 画面の見出しのチップと発言のラベルは `opus`。

## 残っていること

- **v0.1.2 までの記録は直していない**：発言と台帳に GPT の名前が残る。台帳の GPT の名前の分は、Claude Code の推定額。
- **手元のログインで動いたときの費用**：今は推定額（API で払った場合の目安）で記録している。ChatGPT のプランのように「契約枠」として扱うかは未定。
- **ホームの欄の作業場所が「自動」のとき**：人が GPT を選び、右腕がコードの仕事を始めると、会話を作るところで断られる（右腕はその理由を受け取る）。
