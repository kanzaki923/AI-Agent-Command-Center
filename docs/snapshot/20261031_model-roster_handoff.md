## 入ったもの

- **使うモデルの名簿**（仕様 `20261030_model-roster-spec.md`）：設定の「モデル」→ `変更`。`{ model, when }` を上から順に見て、最初に当てはまった行を使う。最下段は固定の「それ以外」（`defaultModel`、人が始めた会話もこれ）。行ごとに典型的な 1 回の費用（`約 $0.48/回`、契約枠は `契約枠`）とここ 30 日の実費。並び替えはドラッグ（ポインタ操作。WebView2 は HTML5 の DnD を自分のファイルドロップに使う）か Alt+↑↓。
  - 選ぶのは右腕（`assistant.startWork`）と監督役（`session.spawn`）。プロンプトに番号つきの名簿・費用・エージェントで使えるか（`llm/roster.ts` `rosterPromptBlock`）。
  - **名簿の外はデーモンが拒む**（エージェントが名指したとき。人は自由、`mock/*` は可）。エージェント（Claude Code）が動かせないモデルも拒む（LiteLLM なしなら Claude だけ）。
  - 接続して最初の Run で名簿が空なら、一覧から 1 回だけ選んで**保存**（`suggestRoster`。契約枠優先、標準＝sonnet / sol / 無印 gpt を「それ以外」、速いモデル＝haiku / mini / luna を 1 行目に）。以後は勝手に変えない。「モデルが設定されていません」はこれで出なくなった。
- **ダイアログの中のポップオーバー**は 61 に上げる（`ui/layer.ts`）。名簿のモデル選びがダイアログの裏に開いていた。
- **右腕の割り振り**：「それぞれチャットを立てて」で監督役 2 人・子 4 人に重複した件。
  - `text` は右腕が書く、その会話への依頼（分けたらその分だけ、人の固有の条件は残し、足さない）。会話では `◇ 右腕` から（押すと右腕へ）。
  - `delegate` は既定値なし・毎回決める。話す・相談・「チャットを立てて」・1 つの作業は false（モデルを変えたいだけなら名簿のモデルを渡す）、並行できる複数の部分とまとめがあれば true、迷ったら false（あとで ◇ で任せられる）。
- **モデルは会話の性質**：見出しの費用の左に小さく `gpt-6.1-sol`（子の会話にも）。押すか Ctrl+M で変えられるが、会話が始まっていれば「途中で変えると、会話を最初から読み直すため費用が増えます」。入力欄のチップはやめた。返答のホバーの列とチップのツールチップにもモデル名。
- **新しい依頼のモデル**：ホームと Ctrl+N の入力欄に「自動」チップ（ツールチップ「設定の名簿に沿って選びます」）。選ぶと `session.send` の `workModel` → メッセージの `meta.hint.model` → 右腕には `モデルの指定:` の行、`startWork` はその Run のきっかけのメッセージから読んで、右腕が何を渡しても（名簿の外でも）そのモデルで立てる。
- 途中で入れて取り下げたもの：実行のたびの完全自動選択（「おまかせ」）。モデルは頻繁に変わり費用も違うので、決めた結果を見える場所に置く形に変えた。「おまかせ」は任せ方のプロファイル名とも重なっていた。

## 残っていること

1. **子の会話の扱い**：監督役の指示が子の会話で人の発言のように見える。挨拶 1 回で子が「完了」になり、その挨拶が成果物（文書）として残る。「人がこれから話すための子」をどう扱うか、設計の相談から。
2. **本物のモデルで未確認**：`delegate` を毎回決める変更、「自動」以外を選んだ新しい依頼。
3. **右腕の会話に Luna が付いている**（人がピッカーで選んだ）。割り振りは判断が要るので Sol を勧めた。仕組みとして縛るかは未定。
4. **GPT-6 / 5.6 系の単価が表にない**：契約枠では 0 なので問題ないが、OpenAI のキーでは目安が `—`、予算の見積もりは最高単価に倒れる。
5. **E2E が古い**：`e2e/slice.js` がもうない `[data-delegate-toggle]` を探す（前の作り直しから）。今回 E2E は回していない。
6. 仕様の「あとで」：ガイドラインを貼って名簿を作る、新しいモデルが出たら名簿に足すか提案、子のチップに当てはまった行を出す。
