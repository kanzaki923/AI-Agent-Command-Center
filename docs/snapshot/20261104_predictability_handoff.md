# 2026-11-04 引き継ぎ：予測できない動きを減らす

使っていて「どう動くかわからない」不安を減らすため、ラベル・見た目と実際の動きのずれを洗い出した（ホーム・サイドバー・会話、パレット・成果物・設定・終了などをコードで追った）。ブランチ `vertical-slice`、`pnpm check` 緑。

## 直したもの（`eea239f`〜`216feb2`）

- **新しい会話（Ctrl+N）が右腕に行く**：会話の入力欄と同じ形の欄で、送ると新しい会話ができて開く（プロジェクト・作業場所・モデルを選べる。プロジェクトの `…` →「新しい会話」もそのプロジェクトになる）。パレットの「AI に頼む」は逆に新しい会話を直接作っていたので、`右腕に頼む` にして右腕へ送り、右腕の会話を開く。
- **ホームの入力欄**：Shift+Enter で送らない。打ちかけの文字は画面を移っても、空のホームがボードに変わっても残る。
- **アーカイブしても動き続ける**：デーモンが木の中の動いているものを止め、繰り返しをオフにする。そうなるときだけ確認（`止めてアーカイブ`）。開いていた会話は親（根ならホーム）へ。右腕にはアーカイブを出さない。表示だけで効かなかった `E`（アーカイブ）・`Space`（覗く）を一覧から消した。
- **終了・再起動の確認文**：「あとで再開できます」→ 設定 `再起動のあと再開` どおりに「任せた作業は、次にアプリを開くと自動で続きを始めます」/「再開するまで止まったままです」。再起動の文が別の設定値を読んで逆のことを言うことがあった（`resumesAfterRestart` に一本化）。Run / Task などの内部の名前を消した。
- **再接続中の終了**：黙って終えてデーモンを残していた。5 秒まで待ち、つながらなければ「接続できません」を出して、押したときだけ終える。
- **ホームの出番の行**：Y の押しっぱなし・連打で次の（読んでいない）承認まで通っていた。承認カードと同じガード。危険度「高」の承認は行の `許可` にキーを付けない。
- **成果物**：コードの `採用` → `採用して反映`。やり直すと同じ実行の判断待ちの成果物も戻ることを、入力欄の下に件数で出す。

## 残っていること（重い順）

1. **作業場所の切り替えはお願いでしかない**（`daemon/assistant.ts` の `workspaceHint`、デーモンの `assistant/service.ts`）。ラジオなのに右腕は別の場所で始められる。モデルの指定はデーモンが強制しているので強さも揃っていない。「制約はデーモンが強制する」に合わせるなら、`session.send` に `workspace` を渡して `assistant.startWork` が従う形。設計の判断が要る。
2. **「止める」の範囲と確認が入口で違う**：ヘッダー・パレットは木ごと確認なし（`stopTree`）、Ctrl+Shift+Backspace・入力欄の ■ はその会話の実行だけで、エージェントなら確認あり。パレットには同じキー表示まで付いている。どちらに揃えるか決める。
3. **接続先のダイアログ**：背景クリックでも「あとで」でも、待っていた依頼を模擬モデルで送り、二度と聞かない（`app/connect.ts`）。
4. **OS の通知を押しても会話が開かない**（Tauri 経路で `onClick` / `tag` を捨てている。`lib/notify.ts`）。
5. **トーストの「ほか N 件」を押すと全部消える**（sticky なエラーも。`Toaster.tsx`）。
6. **繰り返すのポップオーバー**：新規は確定ボタン、既存はラジオを押した瞬間に変わる。やめるは確認なし（`RepeatButton.tsx`）。
7. **「任せ方」の変更は動いている実行に効かない**のに、その旨の表示がない（`SettingsDialog.tsx`）。
8. **コードの全画面ビューの「戻る」が 2 つ**で行き先が違う（`openIntegration` が履歴に積まない）。
9. 細かいもの：レーンの `+N` が親を開く、`Ctrl+F` が画面で意味が変わる、デモが毎週の繰り返しを黙って作る、ホームの作業場所・モデルの選択はボードに変わると戻る。
